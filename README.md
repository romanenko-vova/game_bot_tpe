На этом уроке мы научились с Вами пользоваться кнопочками в телеграм боте.
InlineKeyboardMarkup и ReplyKeyboardMarkup.


1. В функции start сделайте inline кнопочки для перехода в режим разговора и в вашу игру.

2. Сделайте новую ветку GUESS_NUMBER. В ней у нас будет реализована игра "Бот угадывает число".
В функции guess_number_start напишите правила игры и пришлите 2е сообщение с текстом "50?". К этому сообщению прикрепите Reply клавиатуру с тремя кнопками:
"больше", "меньше", "угадал".

3. Напишите функцию guess_number, которая будет запускаться, когда пользователь нажмет на кнопку "больше", "меньше" или "угадал".
И писать человеку сообщение с текстом БОЛЬШЕ, МЕНЬШЕ или УГАДАЛ в записимости от кнопки.
